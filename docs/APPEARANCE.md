# 外观设置

设置页的「外观」卡片用于调整整个界面的语言、主题、字体与排版。所有改动**立即生效**，只保存在当前浏览器本地，刷新或重启应用后仍然保留。

入口：**设置 → 基础设置（Base settings）→ 外观**

---

## 可调项

| 项目 | 取值范围 | 说明 |
| --- | --- | --- |
| 界面语言 | 中文 / English | 切换整个界面的显示语言，与报告语言相互独立 |
| 主题 | 浅色 / 深色 / 跟随系统 | 深色为默认值；跟随系统时随操作系统外观自动切换 |
| 界面字体 | 系统默认 / Inter / Segoe UI / 思源黑体 / 微软雅黑 / Noto Sans | 只使用本机已安装的字体，不下载任何 Web 字体 |
| 基础字号 | 14 / 15 / 16 / 18 / 20 px | 默认 16px；调整后界面元素按比例缩放 |
| 行高 | 1.4 / 1.5 / 1.6 / 1.8 | 默认 1.5；影响正文行间距的疏密 |

### 字体缺失怎么办

选择某个字体但本机没有安装时，会自动回落到系统默认字体，不会出现乱码或空白。想确认效果，直接看下方「预览」区即可。

### 预览区

预览区固定展示一句中英文投资格言，用来直观比对当前字体、字号与行高的实际渲染效果：

> 买在无人问津处，卖在人声鼎沸时。
> Buy when no one is asking; sell when everyone is shouting.

中文与英文同时出现，是为了让中文字形和西文字形在同一块区域里一次看全。

---

## 恢复默认

点击卡片底部的「恢复默认外观」，会同时恢复：

- 界面字体 → 系统默认
- 基础字号 → 16px
- 行高 → 1.5
- 并清除本机保存的外观偏好

界面语言与主题不受此按钮影响，仍由各自的开关控制。

---

## 适用范围

外观设置作用于**当前浏览器**。换设备、换浏览器或使用无痕模式时不会跟随，需要重新设置。

设置存在浏览器的 `localStorage` 里，键名为 `dsa.appearance`，不会上传到服务端，也不会写入分析数据。

清除浏览器站点数据会一并清除外观偏好，界面回到默认外观。

---

## 与其他设置的关系

- **界面语言**：只影响 Web 界面文案；分析报告的输出语言由 `REPORT_LANGUAGE` 控制，两者互不干扰。
- **主题**：与主题切换按钮（顶栏）共用同一份状态，任何一处修改都会同步。
- **字号**：以根字号为单位缩放，所有使用 `rem` 的界面元素一起变化；分享图、导出报告等由后端渲染的内容不受影响。
