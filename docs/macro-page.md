# A股宏观页（外部持仓追踪）

侧栏「A股宏观」用于在同一個界面里查看**汇金、证金及其关联公司**的持仓追踪，数据来自第三方站点 [wangwang-etf.com](https://wangwang-etf.com/)。

入口：左侧栏 → **A股宏观**（路由 `/macro`）

---

## 这页是怎么工作的

页面用 `iframe` 直接加载原始站点，**不抓取、不缓存、不二次加工**第三方内容：

- 鸣谢名单、免责声明、投票等互动区都保留原样，作者署名与版权信息不会被剥离
- 站点哪天更新数据、改版样式，这里自动跟随，无需改代码
- 站点若不可用，本应用不受影响，只是这页显示不出来

## 顶部三个操作

| 操作 | 作用 |
| --- | --- |
| 刷新 | 重新加载内嵌页面（解决偶发白屏或数据未更新） |
| 在新窗口打开 | 在系统浏览器里打开同一地址，适合站点限制嵌入或需要登录时使用 |
| 加载提示 | 15 秒内未完成加载会变成黄色提示按钮，点一下即跳转到浏览器 |

## 显示不出来怎么办

按顺序试：

1. **点「刷新」** —— 偶发的网络抖动最常见
2. **点「在新窗口打开」** —— 如果第三方站点日后加了 `X-Frame-Options` 或 CSP `frame-ancestors`，内嵌会被浏览器拒绝，外链不受影响
3. **确认网络可达** —— 该站点部署在 Cloudflare 之后，需要能正常访问国际网络

## 想换成别的宏观源

地址在 `apps/dsa-web/src/pages/MacroPage.tsx` 顶部的 `MACRO_SOURCE_URL` 常量里，替换成任意支持内嵌的站点即可；若目标站点禁止内嵌，改用「在新窗口打开」的形式承载。
